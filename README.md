# vosk-speech-recogition

## Кратко о проекте

Минимальный Python-пример офлайн-распознавания речи с микрофона через Vosk. Структура: захват и streaming decode в `main.py`, зависимости в `requirements.txt`. Проект интересен компактным real-time ASR-потоком без облачного API; ключевой сценарий запуска — `python main.py --mic --device 1`.

```bash
python main.py --mic --device 1
```
